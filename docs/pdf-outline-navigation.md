# PDF 双语目录导航项目书

## 状态

- 状态：已完成；已通过本功能的构建、定向测试和导航视觉验证。
- 日期：2026-08-09
- 范围：网页前端、共用 FastAPI 后端；桌面端通过重新打包复用前端。

## 目标

将阅读器左侧导航改为“缩略图 / 目录”页签。活动缩略图不再显示上边和两侧蓝框，只保留底部一条直的 2px 选中横线。目录优先读取 PDF 原生书签；原生目录保留英文标题、页码和层级，并单独缓存 AI 中文释义。没有原生目录时，生成并缓存完整可跳转的 AI 双语目录。

## 已确认交互与视觉

1. 左栏打开后默认显示缩略图，可随时切换到目录，不改变面板宽度或拖拽调宽方式。
2. 页签与选中态使用现有阅读器深青色 `#144d5f`；下划线为方头直线，不使用圆角、上弯或完整外框。
3. 目录每项默认显示 English heading，页码右对齐；鼠标悬停或键盘聚焦该项时显示对应中文理解标题，不改变目录行高。
4. 中文释义或 AI 目录正在生成时，在顶部“目录”文字右侧显示小型圆形进度环；有百分比时按进度填充，排队时显示等待转动，完成后自动隐藏。
5. 一级和二级目录可展开/收起；点击项目跳转到对应页。
6. 原生目录存在时保留 PDF 的英文标题、页码和层级；第一次切换到目录自动请求一次 AI 中文释义，不允许 AI 改写目录结构。
7. 原生目录为空时，第一次切换到目录自动生成完整双语目录；生成结果按论文和 PDF 指纹缓存，后续切换只读取缓存。失败后只有用户明确点击“重试”才会再次调用，生成中、失败和可重试状态必须明确可见。

## AI 目录契约

```json
{
  "items": [
    {
      "title_cn": "研究方法",
      "title_en": "Materials and Methods",
      "page": 3,
      "children": []
    }
  ]
}
```

- 只依据带 `[第 X 页]` 标记的当前论文全文生成，不编造章节或页码。
- 优先保留论文中出现的英文原始标题；没有可靠英文标题时，生成简洁对照译文，不伪称逐字原文。
- 支持最多三层、每层最多 40 项，页码必须在论文实际范围内。
- 结果以 `paper_id + 文件指纹 + prompt_version` 缓存；同一篇论文并发打开时只会创建一个生成进程。PDF 文件变更或提示词版本变更后才允许再生成。
- AI 厂商和密钥只在服务器端解析；前端只传可选厂商 ID，不能读取密钥或提交全文。

## 已知风险与归档

- PDF 的原生书签经常缺失、页码可能是内部目标而不是可见页码，因此浏览器需要对无效目标降级为不可点击项。
- 扫描版 PDF 无文字层时，AI 目录不能可靠生成；应提示正文不可提取，不虚构目录。
- 不能让每次点“目录”都重新调用模型；缓存与并发唯一约束是成本和稳定性边界。
- 原生目录的中文释义失败时，继续展示可靠的英文原文和页码，并提供“重试”；不能因翻译失败隐藏原目录。
- 初始视觉稿生成服务出现一次临时 500 错误，使用相同方向的精简提示重试成功；此错误不涉及项目代码。
