# 用户自主配置 AI 模型与百度翻译 API 项目计划书

## 1. 背景与目标
- **现状**：
  1. 划词翻译强依赖后端 `.env` 中的单一百度翻译凭据（`BAIDU_TRANSLATE_APPID` / `BAIDU_TRANSLATE_SECRET`），未实现用户级隔离，且用户无法自行填写和管理。
  2. 原系统可能将管理员私有 DeepSeek Key 写入公共内置厂商，导致所有注册用户共用管理员额度，且不可由用户自由维护。
- **目标**：
  1. 系统基石保持稳定：内置免费的智谱 GLM-4.7 Flash 和全文翻译 SiliconFlow 模型继续保留为各用户自带的基础能力，不可被误删。
  2. 划词翻译百度 API 用户自主化：为每个用户提供独立的百度翻译配置（App ID 与 Secret Key），采用 AES/Fernet 加密持久化存储；支持随时更新保存、测试连通性以及清空/删除配置。
  3. AI 模型自主添加：支持用户自由添加、编辑、切换和删除自己的 DeepSeek 及其他兼容大模型；提供 DeepSeek 等常用厂商的一键快捷填充模版。
  4. 划词面板与配置中心联动：未配置百度翻译时，划词面板给出温和友好的指引卡片及直达配置入口，不再生硬报红。

## 2. 架构设计与技术方案

### 2.1 数据模型（`UserTranslationConfig`）
- 映射表：`user_translation_configs`
- 关联：与 `User` 1对1 关联（`user_id` 外键，级联删除）。
- 字段：
  - `id`: 主键
  - `user_id`: 对应用户 ID（唯一索引）
  - `baidu_appid`: 用户百度翻译 App ID
  - `baidu_encrypted_secret`: 加密存储的百度翻译密钥
  - `updated_at`: 更新时间戳

### 2.2 接口设计
- `GET /api/translation/config`
  - 获取当前用户的翻译配置状态（返回 `baidu_appid`, `has_baidu_secret`, `is_configured`，不泄露明文密钥）。
- `POST /api/translation/config`
  - 保存/更新当前用户的百度翻译配置（支持填入 appid 和 secret，密文入库）。
- `DELETE /api/translation/config`
  - 清空/删除当前用户的百度翻译配置，满足“用户填过的要保存好，也可以删除自己的”要求。
- `POST /api/translation/baidu/test`
  - 测试当前输入或已保存的百度翻译配置连通性（使用 "Hello" -> "你好" 验证），返回成功状态或具体错误原因。

### 2.3 划词服务联动（`selection_insight.py` & `translate.py`）
- `translate_text(text, domain, appid, secret)` 支持传入指定凭据。
- 划词请求到达时：
  1. 读取当前用户配置的百度凭据。
  2. 若已配置且非空，使用用户凭据调用百度翻译。
  3. 若未配置，抛出明确的 `TranslationConfigMissingError` 或友好提示，划词面板识别后渲染“去配置”卡片。

### 2.4 前端界面设计
- **设置中心（`AiConfigPage.jsx`）**：
  - 顶部增加【划词翻译配置（百度翻译 API）】独立卡片：
    - 展示当前状态（已配置/未配置）、App ID 输入框、Secret Key 输入框（带占位提示）。
    - 提供【保存配置】、【测试连通】、【清空/删除配置】按钮。
    - 附带百度翻译开放平台申请引导与免费额度提示。
  - 下方【AI 模型配置】：
    - 智谱 GLM-4.7 Flash 保留系统官方标识（不可删除）。
    - 增强【+ 添加厂商】弹窗：支持一键点击【DeepSeek】等常用模版，自动预填 Base URL 和 Model，用户仅需粘贴 API Key 即可保存；用户自建的厂商卡片支持随时编辑与删除。
- **划词面板（`SelectionInsightPanel.jsx`）**：
  - 百度翻译未配置时展示引导卡片与【前往配置】快捷按钮。

## 8. 2026-09-18 本地独立版方案

- 目标：朋友只安装一个 Windows 安装包，不安装 MySQL、Python、Node.js，也不运行开发启动器。
- 数据：独立模式通过 `XK_READER_STANDALONE=true` 使用 SQLite；数据库、上传 PDF、译文和术语表放在 Electron 用户数据目录。
- 凭据：DeepSeek、GLM、其他兼容 AI 厂商和百度翻译均由每台电脑的用户在“模型与翻译配置”中填写，安装包不携带用户密钥。
- 全文翻译：使用当前用户启用的 AI 厂商；SiliconFlow 不再是强制依赖。外部 API 仍需要联网，这里的“离线”表示不依赖本项目服务器和 MySQL。
- 运行：Electron 启动时拉起打包后的本地 FastAPI 后端；独立模式的全文翻译在后端线程运行，不需要额外 Python worker 启动器。
- 当前状态：SQLite 配置、用户厂商选择和后端线程路径已完成并通过定向测试；PyInstaller 后端目录已生成。PDFMathTranslate 运行时约 0.9GB，standalone NSIS 安装器已生成并核对外置资源目录；仍需在另一台 Windows 电脑实测首次安装和 API Key 配置。
