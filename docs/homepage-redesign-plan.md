# 首页视觉重构计划

## 项目书关联

- 产品总原则：见根目录 `PRODUCT.md`。
- 本次范围：网页版首页“阅读记录”工作区；桌面端通过复用网页版前端获得同样变化。
- 视觉基准：用户确认的 ImageGen 样图 `exec-52ee0202-8629-4486-9f1f-2c940ee8c15a.png`。

## 已确认决策

1. 首页顺序固定为：继续阅读 → 待处理/本周阅读 → 阅读记录。
2. 顶部继续阅读只显示论文名称和最近阅读时间，不显示作者、笔记状态或“笔记可回看”。
3. 最近阅读列表继续保留作者信息，便于区分论文；本次不改变其数据和交互。
4. 延续浅色桌面科研工具风格：深青色主操作、白色内容区、轻分隔线、4-6px 控件圆角。
5. 新规则放入独立首页样式文件，避免继续追加全局 `app.css` 末尾覆盖。

## 易错点与回滚边界

- 不删除 `statusLabel` 等库页面仍使用的状态计算，只移除首页顶部不需要的展示。
- 不把最近阅读列表的作者信息误删；用户确认的“不要作者”只针对顶部继续阅读区域。
- 不修改接口字段、登录判断、打开文献和查看资源回调。
- 如果响应式布局在窄屏下无法容纳统计区，统计项改为纵向排列，不隐藏核心打开文献动作。

## 验收标准

- 顶部只出现论文标题和时间。
- 待处理与本周阅读在同一辅助区内，阅读记录紧随其后。
- 继续阅读、查看资源、待处理行、最近阅读行均保持可点击。
- `npm test`、`npm run build` 通过。
- 桌面端无需单独重写 UI；若发布桌面安装包，再按接手说明重新打包。
